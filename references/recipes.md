# 成品范式：15 个直接可用的组合

每条都是"主风格 + 第二风格 + 主体写法"的完整配方。主体句示范写了对象、摆放、环境，不堆形容词——主体越具体，风格词才越有落点。

用法：把组合喂给 `../scripts/build_prompt.py`，主体换成你的实际内容。

---

### 1. 茶器 / 香器 / 陶瓷静物
**组合**：`CN-01` 宋式美学 + `CO-07` 低饱和度（覆盖色彩）
**主体示范**：一只汝窑天青釉花口盘置于木案，旁置一枝单瓣白梅，素墙背景，晨光自左侧斜入
**为什么**：宋式的"留白 + 哑光 + 柔光"本身就靠低饱和撑住，第二层只压色阶不会再压结构
**注意**：别加"超清 8K"之类的画质词堆叠，宋式的关键在克制

### 2. 国潮主视觉 / 节庆海报
**组合**：`CN-21` 国潮 + `CO-06` 高饱和度（覆盖色彩）
**主体示范**：一个巨大的立体"福"字占据画面中央，四周环绕灯笼、祥云与剪纸纹样，红金两色
**为什么**：国潮本身是"传统元素 + 现代高饱和 + 立体化"，高饱和是它的必要成分而不是修饰
**注意**：国潮易滑向廉价，主体里要点明"立体、有厚度、材质分明"

### 3. 茶室 / 民宿 / 侘寂风空间
**组合**：`CN-08` 侘寂风 + `CO-08` 灰调（覆盖色彩）
**主体示范**：夯土墙老屋一角，一只金缮修补的粗陶罐插着枯枝，麻布上散落几颗干果，午后低角度光
**为什么**：侘寂的"旧"需要灰调来统一，否则粗糙质感会显脏
**注意**：这类空间图常被要求"高级"，加 `CN-01` 反而会互相稀释，二选一

### 4. 人像写真（棚拍 / 情绪片）
**组合**：`PH-06` 人像摄影 + `CO-11` 暖色调 + 浅景深
**主体示范**：三十岁女性侧坐窗边，白衬衫，视线望向窗外，柔和自然光从侧后方来
**为什么**：人像的成败在光位与皮肤质感，风格层只需要定色温
**注意**：负向词务必加"塑料皮肤、过度磨皮、AI 脸"

### 5. 时尚大片 / 品牌 lookbook
**组合**：`PH-07` 时尚摄影 + `PH-01` 胶片摄影（覆盖光影）+ 冷色调
**主体示范**：模特全身站立于水泥灰影棚，廓形大衣，硬光源打亮面部一侧，地面有清晰投影
**为什么**：时尚感来自"硬光 + 高对比 + 胶片颗粒"，三者同属摄影体系，不会打架
**注意**：硬光条件下不要同时要"柔光"，模型会取中间值

### 6. 赛博城市 / 科技夜景观感
**组合**：`DG-03` 赛博朋克 + `CO-04` 霓虹色
**主体示范**：雨后的窄巷，密集招牌与管线向纵深退去，地面积水映出灯光，前景有撑伞行人剪影
**为什么**：赛博朋克的识别度全在"霓虹 + 湿地面 + 密集纵深"，霓虹色只是把光色再推一档
**注意**：主体里写清"夜、雨、纵深"，否则容易出成白天科幻

### 7. 科技产品主图 / 发布会视觉
**组合**：`DG-01` 极简主义 + `CO-12` 冷色调
**主体示范**：一台银灰色金属外壳设备悬浮于纯白背景，单一柔光从顶部打亮，地面有极淡投影
**为什么**：科技产品的"专业感"来自极简与冷色，不需要任何纹理层
**注意**：要求"无文字、无 logo 变形"，负向词加"错误文字"

### 8. 绘本内页 / 儿童故事
**组合**：`IL-07` 绘本风 + `CO-02` 马卡龙色系
**主体示范**：一只戴围巾的小狐狸坐在树桩上，面前摊开一本旧书，周围是秋天的落叶
**为什么**：绘本的柔和水粉质感与马卡龙色同属低对比柔调，叠加后统一
**注意**：儿童内容避免"暗部过重"，负向词加"恐怖、阴森"

### 9. 儿童画风内容 / 亲子活动物料
**组合**：`EX-15` 儿童绘画 + `CO-13` 粉彩
**主体示范**：一家人手拉手站在房子前，天空有一个大太阳，草地画成一片绿色波浪
**为什么**：儿童画的关键是"比例失真 + 蜡笔质感 + 纯色平涂"，粉彩帮它统一明度
**注意**：不要修得太"专业"，过度精修会失去稚拙感

### 10. 节气海报 / 传统文化主视觉
**组合**：`CN-14` 工笔画 + `CO-11` 暖色调
**主体示范**：一枝桂花斜出画面，两只麻雀停在枝上，下方是青瓷盘与月饼，留出右侧文案区
**为什么**：工笔的"三矾九染"层次在暖色下最出彩，且工笔天然适配印刷海报
**注意**：海报需要留白放字，主体里写明"右侧留出文案区"

### 11. 古风人物 / 汉服写真
**组合**：`CN-30` 汉服风 + `CN-14` 工笔画（只覆盖质感与色彩）
**主体示范**：一位女子立于回廊下，齐胸襦裙，手持团扇，身后是雕花木窗与竹影
**为什么**：汉服的形制需要工笔的"绢本质感"来托住，两者同属中国古典体系，不冲突
**注意**：避免混入日式元素（和服领口、鸟居），负向词加"日式元素"

### 12. 日系动画风插画
**组合**：`JP-11`（青蓝与橘粉渐变天空的青春动画）+ `CO-11` 暖色调
**主体示范**：少女站在天桥上望向远处的电车轨道，云层很厚，逆光把发丝打亮
**为什么**：该条目的识别点是"青蓝与橘粉渐变 + 强逆光 + 光晕"，暖色调只做微调不会破坏它
**注意**：这条标了在世艺术家，模板已不含人名，不要自行把作者名写回提示词

### 13. 美食摄影 / 餐饮菜单
**组合**：`PH-01` 胶片摄影 + 暖色调 + 浅景深
**主体示范**：一碗热汤面置于深色木桌，筷子夹起面条，热气在侧逆光中可见，背景是虚化的厨房
**为什么**：食物的诱人度靠"暖色 + 侧逆光 + 浅景深"，胶片颗粒增加真实感
**注意**：写清"热气/水汽"，这是食物图最容易被忽略的细节

### 14. 音乐专辑 / 潮流海报
**组合**：`DG-04` 蒸汽波 + `CO-04` 霓虹色
**主体示范**：一尊古典石膏像置于紫粉渐变的网格地面上，背景是落日与棕榈剪影
**为什么**：蒸汽波的符号系统（石膏像、网格、落日）本身就是拼贴逻辑，霓虹色是它的原生配色
**注意**：蒸汽波容易过曝，负向词加"过曝、噪点"

### 15. 文物 / 博物馆展陈视觉
**组合**：`CN-18` 敦煌壁画 + `CO-07` 低饱和度
**主体示范**：一面斑驳的壁画墙面，飞天衣带飘举，颜料层有剥落与裂纹，侧光擦出肌理
**为什么**：壁画的"时间感"来自剥落与褪色，低饱和压住饱和度才不会像新画的
**注意**：宗教题材不做戏谑化处理，不复现具体洞窟编号的壁画局部
