# 主体写作规范

风格段是常量：173 条模板每条 4–7 段，跑一万次都一样。主体是变量：每次都要现写，而它决定了构图是否成立、空间有没有纵深、画面讲不讲得通。

**同一风格，主体写崩了就全崩。** 本文是稳定性的主要来源，比选风格更值得花时间。

## 一、五要素公式

`对象（谁/什么）+ 数量与材质 + 位置与朝向 + 状态或动作 + 环境线索（光/时间/空间）`

不必五样齐全，但**至少要有"对象 + 位置 + 一条环境线索"**，否则画面没有落点。

示范拆解：

> 一只汝窑天青釉花口盘 · 置于木案正中 · 旁置一枝单瓣白梅 · 素墙背景，晨光自左侧斜入
> └对象与材质┘ └位置与朝向┘ └陪体关系┘ └环境线索（光+空间）┘

## 二、五类场景骨架

| 类型 | 骨架 | 示范 |
|---|---|---|
| 静物 | 主体 + 摆放面 + 陪体 + 背景 + 光向 | 一只粗陶侧把壶立于石台，旁置两只青瓷盏，身后是斑驳白墙，午后侧光 |
| 人像 | 人物状态 + 衣着 + 姿态朝向 + 视线 + 光位 | 三十岁女性侧坐窗边，白衬衫，视线望向窗外，柔光从右后方来 |
| 空间 | 空间类型 + 主家具 + 材质 + 开窗关系 + 时间 | 一间茶室，素面长案正对落地窗，竹帘半掩，竹影落在案面，午后 |
| 风景 | 前中远三层 + 天气 + 时间 + 光线角度 | 前景礁石与野花，中景云海翻涌，远处山脊被染成金橘，日出低角度光 |
| 叙事 | 谁 + 在做什么 + 关键道具 + 环境暗示 | 老人独坐戏院长椅，手里攥着一张旧票根，红色丝绒幕布虚在身后 |

## 三、禁写清单

以下六类写法会被 `../scripts/build_prompt.py` 的主体体检拦下，或至少标出来。

| 禁写 | 为什么 | 改法 |
|---|---|---|
| **风格名**（"新中式茶室"、"水墨山水"） | 风格段里已有，重复加权会过拟合，画面反而更"塑料" | 只写内容："一间茶室"、"一片山水" |
| **空泛评价词**（高级感、唯美、大气、惊艳、氛围感、有故事感） | 模型没有对应的视觉操作，等于没写，只会让画面更"平均" | 换成可拍的具体物："釉面有细密开片"、"桌面只有一只壶" |
| **否定句**（不要杂物、没有人物、避免鲜艳） | 扩散模型对否定处理很弱，"没有人物"经常被理解成"有人物" | 转正向："桌面只有一只壶"、"画面仅此一物" |
| **抽象概念**（孤独、时间流逝、禅意、呼吸感） | 概念不能直接被画，模型只能猜到最俗套的符号 | 换成载体："一个独坐的背影"、"被风翻起的日历"、"石阶上单片落花" |
| **形容词堆叠**（极其精致唯美细腻高级的…） | 三个以上连续修饰会互相稀释，权重被摊平 | 只留一个，其余换成名词细节 |
| **超长句**（>120 字） | 主体过长会挤占风格段的注意力，风格还原度下降 | 压到 20–60 字，删掉解释性从句 |

## 四、真实反例（来自实际使用）

**反例 1**
> 一间**新中式**茶室，落地窗前一张素面长案

问题：主体里带了风格名，风格段再拼一次"新中式"，同一概念被强调两遍。
改：`一间茶室，落地窗前一张素面长案，竹帘半掩，竹影落在案面`

**反例 2**
> 一只孤鹤独立于滩涂浅水，身后是**大片空白**

问题：① "空白"是抽象概念，模型只能猜；② 与"留白"风格的构图段二次加权。
改：`一只孤鹤立于滩涂浅水，远处三五笔坡岸，水面一线淡痕，画面上部大面积不着墨`

**反例 3**
> 一个**很有高级感**的**唯美**茶空间，**氛围感**拉满

问题：三个评价词，零个具体物。这种情况无论配多好的风格，出来的都是"网红样板间"。
改：`一间茶室，夯土墙面，一张原木长案，案上一只粗陶壶冒着热气，午后光斜切过桌面`

## 五、主体与风格的分工

这条界线最容易越界：

| 该写在主体 | 该交给风格段 |
|---|---|
| 光源在哪、从哪个方向来（"晨光自左侧斜入"） | 光是什么质地（"柔和散射光"、"硬光高反差"） |
| 空间有多深（"向纵深退去的窄巷"） | 用什么构图法（"三远法散点构图"） |
| 材质是什么（"粗陶"、"亚麻"、"夯土"） | 质感怎么表现（"颗粒与裂纹质感"、"哑光温润"） |
| 画面里有什么颜色（"朱红的门"） | 整体色彩关系（"赭红、石青、金的碰撞"） |

写主体时问自己一句：**这是"画什么"，还是"怎么画"？**"怎么画"的部分全归风格段。

## 六、长度与自检

- **20–60 字最佳**，低于 10 字太空（模型会自行补全，通常补成最俗套的版本），高于 120 字会稀释风格。
- 交付前跑一次：`python3 scripts/build_prompt.py -s "你的主体" --style <编号>`，看输出的【主体体检】。
- 体检分数 ≥ 85 且无 `[!]` 项，才算主体合格。
