# 易混风格辨析（18 组）

> 这 18 组是实际使用中最高频的混淆点。判断依据全部取自定义库的模板原文，不是主观印象。
> 用法：用户说「想要 XX 那种感觉」而两个候选都像时，读对应组，用「一句话区分」做决策。
> 括号里的数字是原文档编号，可用 `../scripts/find_style.py 46` 或 `--code IL-06` 定位到同一条。

## 1. 吉卜力工作室风格(46 / JP-09) vs 动画导演条目(47 / JP-10)

| 维度 | 吉卜力工作室风格 | 动画导演条目（47） |
|---|---|---|
| 色彩 | 翠绿、天蓝、暖橙的**通透**配色 | 湛蓝、草绿、**飞行器红** |
| 构图 | 广角**全景**，环境为主 | **仰视**的**大动态**，动作与天空为主 |
| 质感 | 手绘水粉厚涂 + 清晰轮廓线 | 水彩手绘**柔和晕染** + 清晰线稿 |
| 光线 | 阳光**明亮通透** | 明亮的**自然天光** |
| 收尾 | 治愈系 | 细腻温暖的怀旧感 |

**一句话区分**：46 是「站在草地上看风景」，47 是「仰头看人飞起来」。
**选择建议**：要氛围场景用 46；要人物动势、飞行、奔跑用 47。
