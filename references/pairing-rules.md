# 元素搭配规则（人工自检）

**为什么单独成文**：`prompt-craft.md` 里的三条冲突规则（媒介、光影、时代）已经写进脚本，跑组装时自动检查。本文件的八条**脚本查不了**——它们判断的是「这套元素搭在一起好不好看」，只能靠写的时候自己过一遍。别指望 `../scripts/build_prompt.py` 会替你拦下来。

用法：元素选定、句子写完之后，按顺序过八条。任何一条不过，回到元素选择重选，不要靠形容词去救。

## 八条规则

### 规则 1 · 主风格只能有一个

一个画面一个主风格，最多再加一个次风格，且次风格只准管色彩或光影。

- **违反后的表现**：水墨 + 超写实 8K 摄影同时存在，模型两头都做一半——山是黑的，纸是塑料的；画面看起来像"滤镜没调完"，观众说不出哪不对，但知道不对。

### 规则 2 · 时代要同代

服饰、器物、建筑、光源技术必须属于同一时代。光源最容易被忽略：烛火、油灯、火把、汽灯、白炽灯、荧光灯、LED 各自锁死一个年代。

- **违反后的表现**：唐制长袍的人物站在不锈钢栏杆前，头顶一盏 LED 吊灯——模型的强项恰恰是"把每个元素都画清楚"，所以穿帮会被画得非常清楚。

### 规则 3 · 同层材质遵守同一套物理

同一层次里的材质要用同一套光学规律。发光符文旁边放哑光麻布没问题，但要说明为什么；否则模型会二选一。

- **违反后的表现**：一半材质有反射、一半像贴纸，交界处出现"抠图感"。

### 规则 4 · 疏密必须有对比

不要全场同密度。焦点区域细节堆满，其余区域敢留空。

- **违反后的表现**：画面处处精彩，等于没有重点；缩到手机上看就是一片灰糊，用户说不清画的是什么。

### 规则 5 · 色彩要有主次

主色约六成、辅色约三成、点缀约一成，点缀色全画只出现一次。细节见 `craft-color-light.md`。

- **违反后的表现**：三四个颜色都很亮、都很饱和，画面刺眼且廉价；模型无法判断哪个颜色重要，于是平均分配，最艳的那个抢走视线——通常不是主体。

### 规则 6 · 光要有出处

每束光都要能在画面里指出来源（窗、灯、火、屏、水面反射、主体自发光）。

- **违反后的表现**：光很漂亮但找不到灯，人物脸上有完美的主光和辅光——这就是"棚拍塑料感"，专业与业余的一半差距在这里。

### 规则 7 · 文化符号不混用

中日韩的符号体系不互通（鸟居 / 牌楼 / 阙，和服 / 汉服 / 韩服不能互换）；用东方符号要知道它的语境（如意、藻井、宝相花各有出处）；宗教符号不随意拼贴。

- **违反后的表现**：中式庭院里出现鸟居，或旗袍配和服腰带。模型会照画，懂行的人一眼看出，整张图的可信度归零。

### 规则 8 · 主视觉元素不超过三个

主元素最多三个，其余全部降为支撑层（环境、氛围、陪体）。

- **违反后的表现**：龙 + 凤 + 八卦 + 铠甲 + 剑 + 樱花 + 雪山 + 月亮同时出现，模型把它们平均化，结果每个都画得像背景板，视觉噪音盖掉主体。

## 常见雷区

| 雷区 | 症状 | 后果 |
|---|---|---|
| 大杂烩 | 一张图塞五个以上文化或风格符号 | 模型折中处理，画面失焦 |
| 色彩无主次 | 每个颜色都饱和、都亮 | 刺眼、廉价、没有焦点 |
| 光源无出处 | 打光漂亮但找不到灯 | 棚拍感、塑料感 |
| 时代错位 | 唐代人物 + 现代器物 + LED 光 | 出戏，且穿帮被画得很清楚 |
| 风格打架 | 水墨与超写实 8K 并存 | 两头不讨好，出现半写实半插画的怪相 |
| 装饰过度 | 没有留白、没有负空间 | 视觉疲劳，气韵堵住 |
| 尺度失真 | 写了「巨大」却没有参照物 | 巨物不巨，史诗感变成杂乱 |
| 视角矛盾 | 「俯视的仰拍」 | 镜头逻辑崩坏，透视失据 |
| 抽象未落地 | 「很有意境」「充满智慧」 | 模型无法执行，只能套最俗的版本 |
| 空转形容词 | beautiful / stunning / amazing 反复 | 语义稀释，等于没写 |
| 主体被淹没 | 主体与环境同密度、同对比 | 看不出画的是什么 |

## 收尾自检

1. 主风格是一个还是两个？次风格管的是色彩或光影吗？
2. 器物、服饰、光源是否同代？
3. 有没有两个颜色在抢戏？点缀色出现几次？
4. 每束光都能指出出处吗？
5. 主视觉元素数一数，不超过三个吗？
6. 焦点区与非焦点区的密度差够不够？

六条全过再交付。任何一条不过，先改元素，再改形容词——形容词救不了搭配错误。
